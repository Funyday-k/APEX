## 关键设计原则

| 原则 | 体现 |
|------|------|
| **数值精确由 CV 保证** | 所有数据点坐标来自像素级 CV 提取，绝不让 VLM 臆造数值 |
| **VLM 仅做语义** | 图类型、图例名、轴标签、单位等语义信息 |
| **人机协同兜底** | 拖拽校正 + 重建图对比 + 置信度提示 |
| **双引擎交叉验证** | CV 系列数 vs VLM 图例数、提取范围 vs VLM 估计范围 |
| **易部署** | Docker Compose 一键，SQLite 零配置，本地 Web 端 |
| **可隐私** | 支持本地 VLM，数据不出本地 |
| **可扩展** | 提取器工厂模式 + VLM Provider 抽象，新增类型/模型零侵入 |
